# Crop Page Redesign Roadmap & Checkpoints

<callout icon="♞">**Status:** In Progress · **Owner:** Sam · **Date:** 2026-09-15</callout>

Implements the frontend work of
[0009-crop-page-redesign-specification.md](0009-crop-page-redesign-specification.md):
the two-mode surface, the Studio bench spine, consent-first removal, one-action
export, a canvas that works over any photo in either theme, and accessibility
parity for the actual framing job.

No backend changes: the thin Workers backend from `0006.1` and [ADR
0008](../decisions/0008-crop-thin-backend-client-removal.md) already stands
(canonical config, metadata-only telemetry, no image bytes on the server). No
new npm dependencies at any phase. No change to the export contract
(`600px` for `2x2`, `300px` for `1x1` at 300 DPI) and no change to the API
surface.

Phases 2–8 are independent enough to be reordered or landed separately; each
one ends with the same gate, so a half-finished phase is still a shippable
state.
