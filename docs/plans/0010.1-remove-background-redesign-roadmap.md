# Remove Background Redesign Roadmap & Checkpoints

<callout icon="♞">**Status:** Implemented · **Owner:** Sam · **Date:** 2026-09-18</callout>

Implements
[0010-remove-background-redesign-specification.md](0010-remove-background-redesign-specification.md):
the `/crop` page shell (back nav, two modes, evidence lane), the bench spine
of stamped plates, the intake funnel, consent-first removal with abort, and
the one-action download — while keeping the tool strictly removal-only.

No backend changes: the thin backend from `0006.1` and
[ADR 0008](../decisions/0008-crop-thin-backend-client-removal.md) already
stands. No new npm dependencies at any phase. No change to the telemetry
event set and no change to the API surface.

Phases 1–4 land in order; each ends with the same gate, so a half-finished
phase is still a shippable state.

## Phase 2 — Island rebuild (`RemoveStudio`)
